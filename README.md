# ACN
This is a placeholder file. The project concentrates on multi-agent systems, with onboard sensing and actualtion. We are experimenting with comms protocols and distributed control of agents. Eventually, agents from their own ego-centric "world model", but importantly they can also share a version of their world models with other agents. Importantly, we are keen on eamining the affects of ML based communication protocols on the performance of the agents. when each agent has it's own limited computational capability.
